Editor de edificios base

Edita identidad, visibilidad, imagen local, niveles, costes, requisitos, capacidad NPC y mejoras vinculadas. El resultado se descarga como buildings.json.

Las imágenes se guardan como ruta, por ejemplo data/pic/bunker.jpg. El navegador no copia archivos a la carpeta; solo deja escrito el nombre correcto en el JSON.
